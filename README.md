# Workbench

PWA that helps digitalize a family workshop's data: bills, workers' logs, payees, cheques and more.

![cover](https://github.com/user-attachments/assets/229a59ca-342f-4190-a32b-95bb1abd16b7)

## Quickstart

```bash
cp apps/api/.dev.vars.example apps/api/.dev.vars && bun install && bun run dev
```

The app is then at `http://localhost:5173` and the API at `http://localhost:8787` (Swagger UI at `/docs`).
